# Community Q&A & Moderation – Moderator User Guide

## Purpose of this Workflow

The **Community Q&A & Moderation Workflow** enables moderators to review community questions and answers, monitor published content, and process user or AI-generated violation reports. Moderators help ensure that community content is safe, appropriate, and aligned with CareBridge policies.

## Step-by-Step User Guide

### Step 1: Pending Manual Review Screen

1. Open **Nội dung mới** from the Moderator Portal navigation.
2. Review content in the **Câu hỏi mới**, **Câu trả lời mới**, or **Đã xử lý** tabs.
3. Select **Xem** to inspect the content, then select **Duyệt**, **Ẩn**, or **Yêu cầu sửa** according to the review result.

![Pending Manual Review Screen](<community_moderator/01-pending-manual-review.png>)

### Step 2: Community Content Monitoring Screen

1. Open **Theo dõi cộng đồng** to view questions and answers currently visible to the community.
2. Switch between **Câu hỏi đang hiển thị** and **Câu trả lời đang hiển thị**.
3. Select **Xem đầy đủ** to inspect the published content and verify that it remains appropriate.

![Community Content Monitoring Screen](<community_moderator/02-community-monitoring.png>)

### Step 3: Violation Reports List Screen

1. Open **Báo cáo** to view reports submitted by users or detected by AI.
2. Use the open or processed tabs, search field, and filters to find a report.
3. Select **Xem** to review the report or **Nhận xử lý** to assign the report to yourself.

![Violation Reports List Screen](<community_moderator/03-violation-reports.png>)

### Step 4: Violation Report Detail Screen

1. Review the report reason, reported content, reporter information, and report history.
2. Select the appropriate moderation action, such as **Duyệt nội dung**, **Xóa bài viết**, **Ẩn nội dung**, **Yêu cầu sửa**, **Cảnh cáo người dùng**, **Hạn chế đăng**, or **Đình chỉ**.
3. Add an optional processing note and confirm the decision.

![Violation Report Detail Screen](<community_moderator/04-violation-report-detail.png>)

## Expected Result

The moderator can review pending content, monitor published community content, process violation reports, and record appropriate moderation decisions for the CareBridge community.
