# Verified Expert Network & Contribution – Step-by-Step User Guide

## Purpose

This guide explains the main Expert Portal screens used for verification, consultation, scheduling, and community contribution.

## Workflow Diagram

![Verified Expert Network & Contribution Workflow](<main_workflow/main work flow-4. Verified Expert Network & Contribution Workflow.drawio.png>)

## Step-by-Step User Guide

### Step 1: Identity Verification Screen

1. Sign in to **ExpertPortal** and open **Xác minh Y tế**.
2. Upload a portrait photo, the front of the identity card, and the back of the identity card using **Chụp ảnh** or **Chọn tệp**.
3. Select **Hoàn tất & Gửi hồ sơ** to submit the identity information for review.

If Admin requests more information, update the required files and resubmit the application.

![Identity Verification Screen](<expert_portal/01-verification-identity.png>)

### Step 2: Verification Completed Screen

1. After the identity and credential review is approved, open the verification result screen.
2. Confirm that all three verification stages are completed and the status shows **Hồ sơ đã được xác minh**.
3. Select **Vào Trang chủ Chuyên gia** to access the verified Expert Portal.

![Verification Completed Screen](<expert_portal/02-verification-complete.png>)

### Step 3: Consultation Requests Screen

1. Select **Yêu cầu tư vấn** from the left navigation.
2. Review the sender, consultation topic, status, and submission time.
3. Accept or decline a request, then select **Vào nhắn tin** for an accepted consultation.

![Consultation Requests Screen](<expert_portal/03-consultation-requests.png>)

### Step 4: Live Chat Screen

1. Open an accepted consultation from the request list.
2. Type a response in the message field and select the send button.
3. Use **Gọi thoại**, **Gọi video**, or the attachment buttons when additional communication is needed.

![Live Chat Screen](<expert_portal/04-live-chat.png>)

### Step 5: Professional Profile Screen

1. Select **Hồ sơ chuyên môn**.
2. Review or update the specialty, professional title, years of experience, workplace, and consultation scope.
3. Save the changes or select **Cập nhật ảnh** to update the profile photo.

![Professional Profile Screen](<expert_portal/05-professional-profile.png>)

### Step 6: Certificates & Documents Screen

1. Select **Chứng chỉ & Giấy tờ**.
2. Review certificate status, issuing authority, issue date, and expiration date.
3. Select **Tải lên chứng chỉ mới** to submit a new or renewed professional document.

![Certificates & Documents Screen](<expert_portal/06-certificates-documents.png>)

### Step 7: Working Schedule Screen

1. Select **Lịch rảnh làm việc**.
2. Use the calendar controls to navigate to the required date or month.
3. Add or review available consultation sessions so families can book an appropriate time.

![Working Schedule Screen](<expert_portal/07-working-schedule.png>)

### Step 8: Community Question Queue Screen

1. Select **Hàng đợi câu hỏi**.
2. Choose a question and review its topic, life stage, priority, and existing answers.
3. Write an expert response and select **Gửi câu trả lời**.

![Community Question Queue Screen](<expert_portal/08-community-question-queue.png>)

## Expected Result

After completing these steps, the expert can use the verified Expert Portal to manage professional information, handle consultations, set availability, and contribute answers to the CareBridge community.
