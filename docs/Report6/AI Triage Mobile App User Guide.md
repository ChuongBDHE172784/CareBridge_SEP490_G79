# AI Triage – Mobile App User Guide

## Purpose of this Workflow

The **AI Triage Workflow** helps mothers and family members describe health symptoms and receive safe, structured guidance. The system evaluates the information using AI and deterministic safety rules, identifies the urgency level, and provides appropriate next steps. When medical care is needed, the user can find nearby hospitals, clinics, or medical stations and receive navigation support.

## Step-by-Step User Guide

### Step 1: Nearby Medical Facilities Screen

1. Review the nearby hospitals, clinics, and medical stations shown on the map.
2. Select a distance range such as **5 km**, **10 km**, or **15 km**, and filter by facility type if needed.
3. Select a facility from the list to view its address, distance, and available actions.

![Nearby Medical Facilities Screen](<ai_triage_mobile/01-nearby-facilities.png>)

### Step 2: Facility Navigation Screen

1. Review the selected facility and the route displayed on the map.
2. Check the estimated travel time, distance, and route information.
3. Select **Dừng dẫn đường** to stop navigation, or use the available call/location options when necessary.

![Facility Navigation Screen](<ai_triage_mobile/02-facility-navigation.png>)

## Expected Result

The user can view nearby medical facilities, select an appropriate location, and follow navigation guidance when medical support is needed.
