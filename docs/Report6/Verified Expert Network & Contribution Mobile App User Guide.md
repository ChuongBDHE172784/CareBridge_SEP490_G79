# Verified Expert Network & Contribution – Mobile App User Guide

## Purpose

This guide explains the main mobile app screens used by CareBridge experts for registration, identity verification, consultation, community contribution, live chat, and schedule management.

## Step-by-Step User Guide

### Step 1: Expert Registration Screen

1. Enter the expert's name, email, phone number, and password.
2. Confirm the password requirements.
3. Select **Tạo tài khoản** to create the expert account.

![Expert Registration Screen](<mobile_app/01-expert-registration.png>)

### Step 2: Identity Verification Screen

1. Capture or upload a live portrait photo.
2. Capture or upload the front and back of the identity card.
3. Select **Gửi ảnh xác minh** to submit the identity information for verification.

![Identity Verification Screen](<mobile_app/02-identity-verification.png>)

### Step 3: Expert Dashboard Screen

1. Review the number of consultation requests and new community questions.
2. Select **Yêu cầu tư vấn** to manage consultations or **Cộng đồng Mẹ & Chuyên gia** to view community questions.
3. Use the bottom navigation to access the dashboard, chat, requests, schedule, and account sections.

![Expert Dashboard Screen](<mobile_app/03-expert-dashboard.png>)

### Step 4: Consultation Requests Screen

1. Open **Yêu cầu tư vấn** from the dashboard or bottom navigation.
2. Use the status tabs to view pending, accepted, or rejected requests.
3. Select an available request to review and respond to the consultation.

![Consultation Requests Screen](<mobile_app/04-consultation-requests.png>)

### Step 5: Community Screen

1. Open **Cộng đồng** to view questions from families.
2. Search or filter questions by topic, life stage, or expert status.
3. Select a question to read the discussion and provide an expert answer.

![Community Screen](<mobile_app/05-community.png>)

### Step 6: Live Chat Screen

1. Open a consultation conversation from the chat or request section.
2. Send messages and share images or location information when necessary.
3. Use the phone or video call options for direct communication with the family.

![Live Chat Screen](<mobile_app/06-live-chat.png>)

### Step 7: Working Schedule Screen

1. Open **Lịch rảnh** from the bottom navigation.
2. Select a date from the calendar.
3. Add or review available consultation time slots and save the schedule.

![Working Schedule Screen](<mobile_app/07-working-schedule.png>)

## Expected Result

After completing these steps, the expert can access the CareBridge mobile app, complete identity verification, manage consultations, contribute to the community, communicate with families, and maintain an available working schedule.
