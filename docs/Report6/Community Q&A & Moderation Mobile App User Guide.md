# Community Q&A & Moderation – Mobile App User Guide

## Purpose of this Workflow

The **Community Q&A & Moderation Workflow** enables mothers, family members, and verified experts to share questions, answers, and health-related experiences. The system scans submitted content for potential policy violations, while Community Moderators review flagged content and decide whether it can be published, edited, hidden, or rejected. Users are notified of the final content status.

## Step-by-Step User Guide

### Step 1: Community Feed Screen

1. Open **Cộng đồng** to view questions and answers from families and experts.
2. Search or filter content by topic, life stage, or expert status.
3. Select a question to read its details, or select **Đặt câu hỏi** to create a new question.

![Community Feed Screen](<community_mobile/01-community-feed.png>)

### Step 2: Ask a Question Screen

1. Enter the question title and detailed description.
2. Add up to three images if needed, then select the topic, related life stage, and priority level.
3. Enable anonymous posting when required and select **Đăng câu hỏi** to submit the question.

![Ask a Question Screen](<community_mobile/02-ask-question.png>)

### Step 3: Question Detail Screen

1. Review the question content, topic, life stage, and existing answers.
2. Read family and expert responses and use the available interaction options when appropriate.
3. Select **Trả lời ngay** to write an answer to the question.

![Question Detail Screen](<community_mobile/03-question-detail.png>)

### Step 4: Submit Answer Screen

1. Review the safety notice before writing the response.
2. Add relevant experience tags, write the answer, and attach up to three images if necessary.
3. Select **Đăng trả lời** to submit the answer for review and publication.

![Submit Answer Screen](<community_mobile/04-submit-answer.png>)

## Expected Result

The user can browse community content, submit questions and answers, view expert responses, and receive the final content status after automated and moderator review.
