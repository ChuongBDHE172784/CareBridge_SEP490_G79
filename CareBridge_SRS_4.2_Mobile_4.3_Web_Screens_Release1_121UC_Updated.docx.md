# **4.1 Release 1 Screen Scope and Traceability**

This document updates the original UC241 screen inventory to the controlled Release 1 baseline of UC-01 to UC-121. It defines 79 active screen specifications: 61 mobile screens and 18 web screens. A screen may support multiple detailed use cases where those use cases are actions within one coherent user outcome. Each entry contains platform, role, feature, priority, related use cases, a regenerated Stitch wireframe prompt and a field-description table.

**Scope decisions applied throughout this screen catalogue:**

• P0 screens come first in the screen order: Account and trust, mother journey, baby care, community, expert network, AI triage and emergency support.

• P1 screens follow: health records, reminders, family sync, verified content, expenses, connected devices and smart activity monitoring.

• Paid consultation, payment, commission, chat/voice/video realtime sessions, disputes/refunds, partner portal and partner service workflows are Version 2 and are intentionally absent.

• Search, filter, sort and pagination are controls embedded in their owning list or browse screen. They are not standalone screens.

• Confirmation dialogs, protected attachment previews and destructive-action confirmations are in-screen states, not standalone screens.

• CC-01 Safety, Compliance and Abuse Prevention is cross-cutting: privacy, consent, access restriction, audit, dangerous-advice blocking and emergency-safe boundaries apply to relevant screens.
